# diablo_app_cerebellum

Robot locomotion control application based on zephyr.

## How to build

### TITA Series
west build -b diablo_apollo -d build_diablo_apollo

### Diablo A1.x Series
west build -b diablo_athena -d build_diablo_athena

### Diablo with Cerebellum EVK(aka A99)
west build -b diablo_apollo_evk -d build_diablo_apollo_evk
